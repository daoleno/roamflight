Credits & Sources

Roamflight is released under the MIT License.

Roamflight is an independent flight exploration game, initially adapted from Sebastian Lague's Geographical Adventures. It is not an official release, not a Unity WebGL build, and not a pixel-identical reproduction of the original video.

Original Work

  • I Tried Creating a Game Using Real-World Geographic Data, Sebastian Lague.
  • Geographical Adventures source project. Terrain meshes, border paths, Earth colour and normal textures, aircraft model, country data, ocean textures and font were taken from the publicly available project.
  • Original project MIT license. Copyright Sebastian Lague. Source assets are pinned to commit 82fcda20bebb033c749b2339e9ce3a6e58007699.
  • Play the original native game.

Geographical Data

The original project credits Natural Earth, GEBCO, and NASA Blue Marble. Geographic borders are shown as supplied in that historical dataset.

Browser Implementation

Three.js (MIT), three-mesh-bvh (MIT), d3-geo (ISC), Lucide (ISC), and Vite (MIT). Cloud geometry, atmosphere and ocean shading, ships, parachute animation, flight controller and delivery UI are browser implementations and differ from the original Unity renderer. Engine audio, environmental ambience, background harmonies and gameplay cues are synthesized locally; no music or audio recordings from the video are included.
