Return to flight

Credits & Sources

This is an independent browser adaptation of Sebastian Lague's Geographical Adventures. It is not an official release, not a Unity WebGL build, and not a pixel-identical reproduction of the original video.

Original Work

  • I Tried Creating a Game Using Real-World Geographic Data, Sebastian Lague.
  • Geographical Adventures source project. Terrain meshes, border paths, Earth colour and normal textures, aircraft model, country data, ocean textures and font were taken from the publicly available project.
  • Original project MIT license, copyright Sebastian Lague. The current public main branch is used; it contains changes made after the first development video.
  • Play the original native game.

Geographical Data

The original project credits Natural Earth, GEBCO, and NASA Blue Marble. Geographic borders are shown as supplied in that historical dataset.

Browser Implementation

Three.js (MIT), three-mesh-bvh (MIT), d3-geo (ISC), Lucide (ISC), and Vite (MIT). Cloud geometry, atmosphere and ocean shading, ships, parachute animation, flight controller and delivery UI are browser implementations and differ from the original Unity renderer. Engine audio is synthesized locally; no music or audio from the video is included.
